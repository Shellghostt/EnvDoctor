# ENV002: Conflicting Node installations or missing target

Component: node. Severity: error.

Multiple Node candidates or a selected manager target are inconsistent.

Fires when the snapshot contains multiple distinct installed Node candidates, or an active/selected target
is missing. It does not require known versions and does not prove that every inactive install is harmful.
Expected targets use `NVM_BIN` or `NVM_SYMLINK`; fnm/volta locations can be identified from observable paths,
but opaque shim selection is not executed or guessed. A failed runtime collector disables the rule.

Verify with `envdoctor diagnose --rule ENV002`. Three-OS fixtures include Node 20.1.0 and 22.1.0, plus
negative/degraded cases. Metadata discovery also tests an nvm 22.11.0 directory without executing its binary.

Suggested fix: Select one Node installation and repair the selected version-manager target.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
