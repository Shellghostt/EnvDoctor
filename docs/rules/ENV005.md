# ENV005: Requested TCP port is already in use

Component: network. Severity: error.

A listening process already holds a port requested for this application.

Use `--port 3000` or `--port 3000,8080`. Network inspection is skipped when no ports are requested.
Only TCP listeners count; established connections alone do not. PID/name come from OS facilities where
permitted; the finding says when ownership is unavailable. It does not terminate a process or change a port.

Verification preserves the relevant ports, for example `envdoctor diagnose --rule ENV005 --port 3000`.
Windows uses native TCP/process APIs, Linux reads `/proc`, and macOS parses lsof field output from a known
installation. A missing inspector degrades the report. Real owned-listener tests passed on Windows and
Linux on 2026-11-14; three-OS fixtures and the CI matrix cover the platform contract.

Suggested fix: Choose another port or stop the identified process after confirming it is safe to stop.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
