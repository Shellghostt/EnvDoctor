# ENV006: Docker daemon unavailable

Component: docker. Severity: error.

The local default Docker engine is stopped, inaccessible, or uses another socket.

Requires a Docker CLI found in a known installation location and a completed probe whose metadata reports
no reachable server. A CLI not found, malformed output or a timed-out/failed collector does not fire the rule.
The probe explicitly uses `/var/run/docker.sock` or the Windows `docker_engine` pipe and removes remote
context overrides. A rootless/custom socket or selected remote context is not checked by this M2 rule.

Verify with `envdoctor diagnose --rule ENV006`. Presence/outage/invalid-output tests use Docker 29.9.2
metadata; a live per-user Docker Desktop installation was detected on Windows on 2026-11-14. Full context
inspection and version-skew rules remain M3, as recorded in ADR 0004.

Suggested fix: Start the local Docker engine and check permission to its default socket.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
