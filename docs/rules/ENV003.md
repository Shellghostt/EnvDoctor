# ENV003: Missing PATH entries

Component: path. Severity: warning.

PATH references directories that no longer exist.

The evidence preserves each missing entry exactly as stored in PATH, including whitespace and quotes,
except that the current home path is replaced with `~`. Empty elements are omitted under the M1 contract.
Permission/inspection failures degrade the PATH collector rather than invent missing-directory evidence.
OS errors for malformed Windows paths, overly long paths and non-directory ancestors are reported as
broken entries. An existing regular file on PATH and shell startup settings remain outside this rule.

Verify with `envdoctor diagnose --rule ENV003`. Positive, negative and failed-collector fixtures cover
all three OS snapshots; raw-entry, quoting, malformed-path and permission behavior have collector regressions.

Suggested fix: Remove or correct these entries in your shell or system PATH settings.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
