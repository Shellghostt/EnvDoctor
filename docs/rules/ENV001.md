# ENV001: Conflicting active Python versions

Component: python. Severity: error.

Active Python command aliases resolve to different installed versions.

Requires at least two distinct known versions on active `python`/`python3` resolutions. Extra inactive
Python installations alone do not fire this rule. Unknown versions and a failed runtime collector do not
provide conflict evidence. Versions come from manager paths, PE resources or `pyvenv.cfg`; system Unix
binaries and opaque shims may remain unknown because discovered interpreters are never executed.

Verify with `envdoctor diagnose --rule ENV001`. Fixtures compare Python 3.11.1 and 3.12.1 across all
three OS snapshots. Venv/symlink behavior is also tested on Linux; native Windows and Linux suites passed
on 2026-11-14. Updated macOS execution remains in the CI matrix.

Suggested fix: Activate the intended environment and align python and python3 on PATH.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
