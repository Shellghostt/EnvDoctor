# ENV004: Selected runtime is shadowed on PATH

Component: path. Severity: warning.

An earlier PATH candidate takes precedence over the selected environment.

The snapshot must identify an existing selected runtime that is inactive, plus a different active runtime
of the same family. Selection comes from `VIRTUAL_ENV`, `NVM_BIN` or `NVM_SYMLINK`. Missing selected
targets are not shadowing evidence; ENV002 covers missing Node targets. Failed PATH/runtime inspection
disables this rule. Python venv invocation paths remain distinct even when they share a system symlink target.

Verify with `envdoctor diagnose --rule ENV004`. Three-OS fixtures cover selected versus active targets;
Linux tests exercise the venv/system symlink case without executing the interpreter.

Suggested fix: Activate the selected environment or move its bin directory before the conflicting entry.

No command is executed by this rule. Evidence comes only from the snapshot. Unknown or failed collectors do not produce guessed findings. Positive, negative and edge fixtures cover Windows, Linux and macOS.
